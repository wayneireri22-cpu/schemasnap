# SchemaSnap ⚡

JSON to TypeScript, Zod & JSON Schema converter.

Paste any JSON. Get clean types in your format. All in-browser — nothing leaves your machine.

## Features
- 🔄 Convert JSON to TypeScript interfaces
- 🔄 Convert JSON to Zod schemas  
- 🔄 Convert JSON to JSON Schema
- ⚡ All conversion happens client-side (zero server cost)
- 📋 One-click copy

## Deployment

### Vercel (recommended)
```bash
npx vercel deploy
```

### Local
```bash
npm start
# → http://localhost:3000
```
